# /models Folder

## Overview

This folder contains all the CAD files required to rebuild our robot. Note that for assembly, the main README.md should be referred to, as it has detailed steps of how to reproduce our robot.

## Folders:
- **CAD_drawings:** Contains CAD drawings of dimensions of laser-cut parts, as well as a center of mass diagram.
- **DXF:** Contains “.dxf” files required for **laser cutting** and **CNC cutting**.
- **STEP:** Contains “.step” files including our entire bot assembly.
- **STL:** Contains “.stl” files required for **3D printing**.

## Other:
- **Gifs:** Contain gifs rotating our bot’s CAD file to show the entire robot.
- **robot_comparison.png:** Contains a side-by-side comparison of our first robot iteration and our final robot.
